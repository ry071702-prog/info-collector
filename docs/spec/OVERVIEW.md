# info-collector ってなに？（やさしい説明）

> 技術にくわしくない人向けの「これは何で、何ができて、どう使うか」の説明です。
> くわしい設計は [SPEC.md](SPEC.md)、自分で作ってみたい人は [REBUILD_PROMPT.md](REBUILD_PROMPT.md) を見てください。

公開サイト: https://info-collector-a5y.pages.dev/

---

## ひとことで言うと

**「ゲーム・アニメ・Disney のニュースを、ネット中から自動で集めて、AI が要約・仕分けして、毎日まとめてくれる自分専用のニュース係」** です。

人が SNS を見張る代わりに、プログラムが 24 時間ずっと情報を集め続けます。

---

## 何をしてくれるの？

```
   いろんな情報源              AIが処理              受け取り方
 ┌──────────────┐      ┌──────────────┐     ┌──────────────┐
 │ X (Twitter)  │      │  仕分け       │     │ サイトで読む │
 │ YouTube      │ ───▶ │  要約         │ ──▶ │ Discordに通知│
 │ Twitch       │      │  重要度づけ   │     │ Notionに保存 │
 │ ニュースRSS  │      │ (S/A/B/C)     │     │ 毎日まとめ   │
 └──────────────┘      └──────────────┘     └──────────────┘
```

1. **集める** — X・YouTube・Twitch・ニュースサイトから新着を自動で取ってくる
2. **仕分ける** — AI（Gemini）が「ゲーム？アニメ？Disney？」「新作情報？大会？グッズ？」を自動分類
3. **要約する** — 長い投稿を短くまとめる
4. **重要度をつける** — S（最重要）/ A / B / C の4段階。SやAは見逃さないようすぐ通知
5. **届ける** — 専用サイト・Discord・Notion・毎日のまとめ記事、好きな形で受け取れる

---

## どんなとき役に立つ？

- 推しジャンルの情報を **追いきれない** → 自動で集めて要約してくれる
- 重要な発表（新作・コラボ・大会）を **見逃したくない** → S/A は即通知
- あとで見返したい記事を **整理しておきたい** → Notion に自動で溜まる
- 毎朝「昨日の重要ニュース」を **ダイジェストで読みたい** → 日次まとめが届く

---

## お金はかかるの？

**ほぼ無料**です。

- 使っている AI（Google Gemini）は無料の範囲だけで動くよう設計
- 動かす場所（GitHub Actions）も無料枠
- 例外は「新聞風のまとめ画像」を作る機能だけ。きれいな日本語の画像を出すために、ここだけ有料の画像 AI を使っています（**1日1枚で月¥600〜1,100ほど**）

## 何が見られるの？（公開サイト）

https://info-collector-a5y.pages.dev/ で、集まった情報を誰でも閲覧できます。

- ジャンル別ページ（ゲーム / アニメ / Disney）
- 日々のダイジェスト
- 1日1枚の「新聞風」まとめ画像
- キーワード検索・お気に入り
- 「気になった記事を保存して AI に要約してもらう」機能（※これだけは本人用パスコードが必要）

---

## 仕組みの特徴（むずかしくない範囲で）

- **人が常に見張らなくていい** — 決まった時間に勝手に動く（30分ごと〜1日1回）
- **一部が失敗しても全体は止まらない** — 例えば X が取れなくても YouTube は普通に動く
- **集める対象は表で管理** — 「この人もフォローしたい」を一覧表（CSV）に足すだけ。プログラムは触らない
- **AI の使いすぎを自動でセーブ** — 無料枠を超えそうになると自動でブレーキ

## 「自分も似たものが欲しい」と思ったら

このプロジェクトは、AI コーディングツールに丸ごと指示して再現できるように **作り方そのものを文書化** しています。
[REBUILD_PROMPT.md](REBUILD_PROMPT.md) を AI に貼り付ければ、ジャンルを変えた自分版（例: 「料理」「スポーツ」専用）も作れます。

実際に動かす手順（API キーの取り方など）は [SETUP.md](../../SETUP.md) に、30〜60分で本番稼働まで書いてあります。

## 用語ミニ辞典

| 言葉 | かんたんな意味 |
|---|---|
| 収集（collect） | ネットから新着を取ってくること |
| 分類（classify） | AI がジャンルや種類を仕分けること |
| ダイジェスト | その日の重要ニュースのまとめ |

| watchlist | 集める対象（アカウントやサイト）の一覧表 |
| Discord 通知 | チャットアプリにお知らせが飛ぶこと |
| Gemini | Google の AI。仕分けと要約を担当 |
| GitHub Actions | 決まった時間に自動でプログラムを動かす仕組み |
